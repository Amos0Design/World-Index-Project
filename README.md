Howdy y'all

This repository is being used to provide data for the project at: https://www.amos.design/the-civic-atlas

The Civic Atlas is an interactive 3d globe of our world with data overlays for governmental type, direction of power, and a number of leading freedom and democracy indices. The repository includes older versions of both the raw index data and GEOJSON providing territorial information. 

Enjoy the project and feel free to use the compiled index data for other educational and informative projects.
